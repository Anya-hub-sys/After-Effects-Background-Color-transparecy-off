# After Effects Background Color Automation

An After Effects script that turns off the Transparency Grid in every composition and sets a default background color, so your previews and workspace look the same across the whole project.

## File
- `set_all_comp_backgrounds.jsx`

## How to use
1. Open your After Effects project.
2. Go to **File → Scripts → Run Script File** and select `set_all_comp_backgrounds.jsx`.
3. (Optional) To change the background color, open the script in a text editor and edit the color value before running it.
4. The script updates all compositions in the project automatically.

## Tips
- Save a backup of your project before running the script.
- To run it from the Scripts menu, copy the file into After Effects' `Scripts` folder and restart the app.
